# MacClean v0.3.0 · Apple Silicon 预览版

原生 macOS 空间分析、保守清理建议、应用卸载和可恢复操作。源码按 MIT 许可证公开。

本版加入建议删除、建议保留、必须保留三类判断，手动保留设置跨扫描保存。一键清理仅在本人点击后处理建议项，先重检内容、运行状态与占用，再移入系统废纸篓；扫描结束不会自动删除。

## 下载安装

- `MacClean-0.3.0-arm64.dmg`：打开后拖入 Applications。
- `MacClean-0.3.0-arm64.app.zip`：解压后的应用与 DMG 版本相同。
- `MacClean-0.3.0-docs.zip`：包含 README、全部说明图文、隐私边界、验收说明和许可证。
- `SHA256SUMS.txt`：三个附件的完整性校验清单。

**仅提供 Apple Silicon arm64。最低部署目标 macOS 14；跨设备和全部系统版本兼容性尚未验收。使用 ad-hoc 签名，未经过 Apple 公证，不是稳定发行版。**
