# 隐私与清理边界

## 运行时数据

本版扫描、建议和恢复记录在本机处理。没有账号登录、遥测、云端上传或联网模型服务；建议使用本地规则，不发送文件内容给 AI。只读扫描读取路径、类型、大小、修改时间和文件系统元数据，不解析文件内容。

判断程序使用状态会读取本机进程的可执行程序名称及运行应用 Bundle ID，不读取命令行参数。执行清理前使用本机 `lsof` 检查目标占用，超时或状态无法确认时保留。

清理历史存放在 `~/Library/Application Support/MacClean/history.json`，保留偏好在同目录 `keep.json`，权限设置为 `0600`。记录含原路径和废纸篓路径，请勿直接公开。

## 本次公开版本如何脱敏

- 源码和发布文档不包含真实用户名、个人目录、真实扫描报告或应用清单。
- 说明图重新使用虚构数据生成，不在真实截图上简单遮挡，不读取本机历史。
- 安装包移除了编译时绝对源码路径；构建脚本关闭调试信息、映射工程路径，并在签名前剥离调试符号与本机 Swift module 路径。
- AppKit 生成的 PNG 元数据仅允许分辨率、单位与像素尺寸；不允许位置、设备、作者或文本记录。
- `.build`、恢复/保留记录、旧版桌面备份、原始截图、`.DS_Store` 和私有配置不进入 Git。
- 发行附件仅含当前应用、公开图文说明及 SHA-256 校验清单，不含构建缓存。

脱敏并不表示运行后的报告匿名化：用户本机导出的 JSON 和截图仍可能包含真实信息。提交 Issues 前请检查用户名、路径、文件名和其他不想公开的内容。

## 可以恢复，不等于备份

本版将文件移入系统废纸篓，不执行永久删除。恢复依赖原文件仍存在、原父目录可用且没有冲突。清空废纸篓后不能通过本工具找回；重要文件仍应另行备份。

## 保护规则与已知限制

系统目录、关键用户数据、模型共享存储、数据库、虚拟磁盘、照片资料库、版本库内部和共享组容器等受到保护。应用关联数据仅在明确卸载入口中由本人逐项选择。

进程名和元数据判断不能保证识别所有使用关系。执行检查与移动之间仍存在短暂竞争窗口，跨版本和真实窗口交互尚未完成全面验收。本版为早期工具，首次使用建议只读扫描小范围、核对结果。

本版使用 ad-hoc 签名而非 Developer ID 签名，未经过 Apple 公证；源码公开和校验清单不等于安全审计或 Apple 背书。
