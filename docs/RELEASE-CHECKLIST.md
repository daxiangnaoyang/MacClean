# v0.5.0 发布检查

本清单用于源码与附件验收；真实运行报告只保留在本机。最终通过项目以发布提交中的状态为准。

- [x] Release 构建与真实临时文件的一键清理/恢复集成测试。
- [x] 运行中应用与开发工程保护改为运行时路径，不嵌入编译机器路径。
- [x] 应用版本为 0.5.0、可执行文件为 arm64、ad-hoc strict 签名通过。
- [x] 八张原生演示图目视检查；没有真实用户目录或应用清单。
- [x] Markdown 本地图文链接有效，完整说明包可离线解压。
- [x] 公开源码、二进制与打包文件中没有发现本机私有路径或凭据格式。
- [x] DMG 只读挂载与 ZIP 解压后签名通过，版本和可执行文件与发布应用一致。
- [x] 三个发行附件的 SHA-256 校验通过。
- [x] Git 暂存清单排除真实报告、历史/保留记录、构建缓存、桌面旧版备份与私有配置。

不在通过范围：Apple 公证、Developer ID 签名、Intel 发行包、跨设备/全部系统版本兼容性、全面窗口交互验收、专业安全审计。不得把清单勾选解读为这些项目已通过。
